https://telalucis.org/

An online library of philosophical texts that shows the reader what other author's have been saying about the page/passage they are currently reading. Books are imported by a spider that reads books from archive.org, scans their pdfs using surya ocr, then uses gpt-4o to extract footnotes and link citations with other works in the database. After a work is scanned, all of the citations are checked and if any of them point to books that are not in the database yet, but that exist on archive.org it will attempt to download them and add them to the database.
